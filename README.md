# BlackPearl_AIC_CompFest (LegacyMind AI)

## Setup Guide (Localhost)
Proyek ini menggunakan Docker untuk mempermudah replikasi environment.

### Cara Menjalankan:
1. Pastikan Docker dan Docker Compose sudah terinstall.
2. Jalankan perintah berikut di root terminal:
   `docker compose up --build`
3. API dapat diakses melalui `black-pearl-aic-comp-fest-khpfq0lxl-maccreas-projects.vercel.app`
